# mkultra.py

Jump and run game.

## Installation

This project uses Poetry for dependency management. To install and run the game:

### Prerequisites

- Python 3.10 or higher
- Poetry (https://python-poetry.org/)

### Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/mkultra.py.git
cd mkultra.py
```

2. Install dependencies using Poetry:

```bash
poetry install
```

3. Run the game:

```bash
poetry run python mkultra.py
```

### Alternative: Using pip (legacy)

If you prefer not to use Poetry, you can install dependencies with pip:

```bash
pip install -r requirements.txt
```

Then run the game:

```bash
python mkultra.py
```

## Development

For development, you can use Poetry's virtual environment:

```bash
poetry shell
# Now you can run Python commands directly
python mkultra.py
```
